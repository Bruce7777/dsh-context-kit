## 输入 token 对比

默认主动裁剪关闭。下表输入均计入辅助摘要请求；合成数据是宿主估算，真实会话是 provider usage。

| 场景 | 无插件 | 默认插件 | 变化 |
|---|---:|---:|---:|
| 8 步合成会话 | 42,032 | 43,760 | +4.11% |
| 96 步合成会话 | 4,630,382 | 4,649,006 | +0.40% |
| 512 步合成会话 | 130,050,259 | 37,479,646 | **−71.18%** |
| 真实会话首次只读核查 | 1,371,971 | 773,636 | **−43.61%** |

512 步会话包含 4 次摘要，最大单次输入从 506,378 降至 130,885。8/96 步未达到默认预算，只有工具 schema 的固定成本；本次基准每请求增加 192 个估算 tokens。

显式开启主动裁剪的另一组真实 Bash 工具测试，输入减少 35.77%，89 次被替换结果的小 metadata 均逐字保留，但本地耗时增加 5.58%。真实 read 组的大 metadata 保护使其没有裁剪；这组不能当作所有工具输出都会节省的证据。

## 缓存和真实费用

同一历史切点、同一提示，保留实际模型与最大推理设置，分别做无插件、首次启用、暖缓存复测。调用路径和输出仍有模型随机差异。

| 指标 | 无插件热历史 | 插件首次启用 | 插件暖缓存复测 |
|---|---:|---:|---:|
| 未命中输入 | 2,883 | 702,980 | 66,464 |
| 缓存读取输入 | 1,369,088 | 70,656 | 853,248 |
| 总输入 | 1,371,971 | 773,636 | 919,712 |
| 总输出 | 3,115 | 4,870 | 11,900 |
| 主请求 + 摘要请求 | 2 + 0 | 2 + 1 | 4 + 1 |
| 整轮耗时 | 32.06 秒 | 42.38 秒 | 81.89 秒 |

暖缓存摘要读取 635,672 输入中的 635,520 tokens，命中约 **99.98%**。首次启用有大量冷填充；按测量日官方 Flash 非高峰单价计算，三轮费用约为 **$0.00641 / $0.10858 / $0.01967**，这是用量估算而非账号账单。**两轮插件短核查均比已充分命中的无插件基线贵。** 因此，输入减少不直接代表费用减少，也不能从这些样本宣称延迟不增加。

## 本地性能

Node 24.15.0、macOS x64，每变体 3 个新进程样本，中位数。真实 AgentLoop/Session/工具/meter，模型脚本化；不包含初始化和模型/网络延迟。prefix 诊断与计时分开。

| 96 步工作负载 | 无插件 | 默认插件 | 差异 |
|---|---:|---:|---:|
| 合成工具 | 211.12 ms | 224.49 ms | +6.33% |
| 真实 read | 450.81 ms | 451.29 ms | +0.11% |
| 真实 Bash 子进程 | 7242.28 ms | 7180.99 ms | −0.85% |

同工具目录的 Basic 对照为 227.15 ms。合成组 retained heap delta 约 2.115 → 2.114 MB，RSS 82.88 → 85.31 MB；真实工具组 RSS 也有增加。有限样本不能证明所有工作负载零回归。
